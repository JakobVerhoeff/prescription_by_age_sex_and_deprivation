# Prescription by Age, Sex and Deprivation

Authors: Jakob Verhoeff, Naomi Waterlow, Gwen Knight

## Overview

This repository contains the analysis code for antibiotic prescribing patterns in England by age, gender, and deprivation (IMD), using FOI data from NHS BSA for financial years 2015/16 to 2022/23.

## Pipeline

| Script | Purpose |
|--------|---------|
| `01_data_cleaning.R` | Loads raw FOI, IMD, ONS, and lookup data. Links GP practices to LADs/LSOAs via postcodes. Joins population denominators and antibiotic group mapping. Outputs `combined_data.csv` and `combined_data_lsoa.csv`. |
| `02_data_exploration.R` | Descriptive exploration: population structure by IMD (pyramids, age/sex tests), prescribing rates by antibiotic family, IMD, age, and gender. |
| `03_model.R` | Fits nested negative binomial GLMMs (m0-m9) for all antibiotics combined and each antibiotic family. Compares models by AIC, extracts IRRs, generates coefficient and forest plots. |
| `04_linkage_comparison.R` | Compares LAD vs LSOA linkage methods. Crude and age-sex standardised prescribing rates by IMD quintile. |

See `DATA_DESCRIPTION.md` for detailed documentation of all input and output data files.

## Data sources

All datasets used in this analysis are publicly available:

- **FOI prescription data** (NHS BSA, FOI-02243): https://opendata.nhsbsa.net/dataset/foi-02243/resource/e45ebfda-a8af-43b2-a74e-f4436eadbc6f
- **Index of Multiple Deprivation 2019** (MHCLG): https://www.gov.uk/government/statistics/english-indices-of-deprivation-2019
- **GP practice to postcode lookup** (NHS England e-Practitioner Register): https://digital.nhs.uk/services/organisation-data-service/data-search-and-export/csv-downloads/gp-and-gp-practice-related-data
- **Postcode to LAD/LSOA lookup** (ONS, February 2024): https://geoportal.statistics.gov.uk/datasets/80592949bebd4390b2cbe29159a75ef4/about
- **Population estimates by LAD, age, and sex** (ONS mid-year estimates, mid-2011 to mid-2024): https://www.ons.gov.uk/peoplepopulationandcommunity/populationandmigration/populationestimates/datasets/estimatesofthepopulationforenglandandwales
- **Population by IMD decile, age, and sex** (ONS adhoc request 12386): https://www.ons.gov.uk/peoplepopulationandcommunity/populationandmigration/populationestimates/adhocs/12386populationbyindexofmultipledeprivationimdengland2001to2019
- **BNF antibiotic reference tables** (NHS BSA): provided with FOI response

```
└── archive/                                # Unused legacy data files
```

## Reproducing the analysis

Run scripts in order: `01` -> `02` -> `03` -> `04`. Script `01` must be run first as it generates the combined datasets used by all subsequent scripts.

**Requirements:** R (>= 4.0) with packages: `tidyverse`, `janitor`, `readxl`, `glmmTMB`, `broom.mixed`, `marginaleffects`, `AICcmodavg`.

Note: `03_model.R` fits 10 models for each of 14 antibiotic families and may take considerable time to run.
